# 金雀工作台

一个简洁的巴洛克风任务与时间管理工作台，包含：

- 灵感与事务快速记录
- 时间管理四象限分类
- 任务拆分与个人时间表
- 每日确认卡片
- 25 分钟番茄钟
- 可安装到手机桌面的 PWA
- 中文语音输入（识别后可编辑，再收入匣）

所有任务数据默认保存在浏览器本地存储中。

## GitHub Pages

把压缩包内容提交到 `main` 分支后，内置的 GitHub Actions 工作流会自动发布。首次使用时，请在仓库的 **Settings → Pages** 中将发布源设为 **GitHub Actions**。

发布完成后，用手机打开 HTTPS 地址：Android 可点页面中的“安装 APP”，iPhone 可用 Safari 的“分享 → 添加到主屏幕”。语音输入需要允许浏览器使用麦克风；若浏览器不支持网页语音识别，可使用手机键盘自带的听写按钮。
